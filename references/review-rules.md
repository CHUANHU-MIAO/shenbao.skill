# 材料核对规则

## 总则

1. **先看要求，再看文件。** 没有要求依据时，只能给通用建议，不能判“不符合”。
2. **只核对材料，不判断申报结果。**
3. **不一致就是风险。** 公司名称、统一社会信用代码、法人、金额、年度、人员数量，任何一处不一致都要指出。
4. **文件本身也要看形式。** 盖章、签字、日期、页码、目录、份数、格式、命名、大小。
5. **不确定就写“无法判断”。** 不猜、不补、不替客户编。

## 主体资格

### 营业执照

- 名称与申报主体、所有附件一致
- 统一社会信用代码一致
- 经营范围覆盖申报业务
- 在有效期内；副本/复印件要求
- 年检/公示信息（如通知要求）
- 加盖公章、清晰、彩色扫描
- 常见缺口：只给正本、缺副本、盖章不清、经营范围不含申报业务

### 法人/经办人证明

- 法人身份证正反面
- 授权委托书：法人签字、公章、日期、被授权人信息
- 经办人身份证
- 常见缺口：授权书没盖章、日期空、权限写错

### 信用/无违法证明

- 信用中国/国家企业信用信息公示系统截图
- 日期在通知要求的时间段内
- 无重大违法、经营异常、失信记录
- 常见缺口：截图过期、只截一半、没显示查询日期

## 财务

### 审计报告

- 年度齐全（通常近 2～3 年，以通知为准）
- 审计意见类型（无保留意见）
- 资产负债表、利润表、现金流量表
- 会计师事务所盖章、注册会计师签字
- 报告文号、页码
- 数据与纳税申报/财务报表一致
- 常见缺口：缺年度、缺附注、只有封面、数据对不上

### 财务报表/纳税证明

- 报表期间、单位（元/万元）
- 资产负债表平衡
- 收入、利润、研发费用口径一致
- 纳税证明的所属期、税种、金额
- 常见缺口：报表未盖章、期间不匹配、单位写错

### 研发费用

- 研发费用辅助账/专项审计
- 归集口径（人员人工、直接投入、折旧、设计、其他）
- 与研发项目、人员名单对应
- 占收入比例是否达到通知要求
- 常见缺口：只有总数没有明细、费用与项目对不上、跨年归集错误

## 研发/项目

- 立项文件：时间、编号、负责人、预算、目标
- 过程材料：会议、测试、阶段报告
- 验收/结题：验收意见、签字、日期
- 查新/检测/用户报告：机构资质、日期、结论
- 产学研：合作协议、双方盖章、实际支付/合作证明
- 常见缺口：立项晚于研发费用、验收无签字、项目与知识产权无关联

## 知识产权

- 专利/软著/商标证书：权利人、发明人、授权日、有效期
- 与主营业务/申报项目的关联说明
- 受让/许可：合同、备案、独占许可
- 缴费凭证/年费（专利）
- 常见缺口：权利人与申报主体不一致、证书过期、受让未备案、与项目无关

## 人员

- 社保缴纳证明：人数、月份、单位
- 劳动合同：期限、岗位、盖章
- 学历/职称证书
- 研发人员名单：姓名、岗位、学历、工作内容
- 研发人员占比计算
- 常见缺口：社保人数与名单不一致、兼职/劳务未说明、名单无岗位

## 业绩

- 合同：甲方乙方、金额、服务内容、签字盖章、日期
- 发票：金额、税号、货物/服务名称
- 验收/用户报告：甲方盖章、日期、结论
- 合同-发票-验收三者对应
- 常见缺口：只有合同没发票、金额不一致、甲方未盖章

## 制度/体系

- 质量/环境/职业健康/知识产权/研发管理制度
- 文件发布令、版本号、生效日期
- 体系证书：认证机构、范围、有效期
- 制度与实际执行记录（培训、内审、管理评审）
- 常见缺口：制度是模板、无发布令、证书范围不覆盖

## 承诺/附件/格式

- 承诺书使用当年模板，不套旧版
- 法人签字/盖章/日期，不能空白
- 封面、目录、页码、骑缝章
- 份数、正副本、装订方式
- 线上附件：PDF、大小、命名、上传位置
- 常见缺口：承诺书旧版、只盖章没签字、缺目录、文件超过系统限制

## 输出检查表

每份材料至少看：

- [ ] 主体名称/代码一致
- [ ] 有效期覆盖申报期
- [ ] 关键数字与要求一致
- [ ] 盖章/签字/日期
- [ ] 附件/页码齐全
- [ ] 格式/命名/份数
- [ ] 与清单其他材料不矛盾
