# 输出模板

## 1. 第一版材料清单（聊天精简版）

```markdown
## 申报事项
- 公司：
- 事项：
- 地区/年份/批次：
- 截止：
- 要求来源：

## 材料清单（V1）
共 N 项：必须 N、加分 N、格式 N、待确认 N。

| 编号 | 类别 | 材料 | 必须性 | 形式要求 | 当前状态 |
|---|---|---|---|---|---|
| M01 | 主体资格 | 营业执照副本 | 必须 | PDF，盖章 | 未提供 |
| M02 | 财务 | 近三年审计报告 | 必须 | 审计报告全文，盖章 | 未提供 |

清单已保存到：`申报事项/.../03-材料清单.json`

要不要现在开始逐项核对材料？从 M01 开始。
```

## 2. 单项核对

```markdown
【M01 营业执照副本】
要求：合法有效，经营范围覆盖申报业务，加盖公章。
现有：营业执照副本扫描件，名称与申报主体一致。
结论：符合要求 / 部分符合 / 不符合 / 无法判断 / 未提供
依据：通知第 2 页“申报材料”第 1 条；文件第 1 页。
缺口：无 / 缺年检页 / 经营范围未覆盖 / 盖章不清。
整改：补最新副本并加盖公章，扫描为 PDF。
```

## 3. 最终比对清单

```markdown
# 材料比对清单

- 公司：
- 申报事项：
- 要求来源：
- 核对日期：

| 编号 | 申报要求 | 要求要点 | 现有材料 | 是否符合要求 | 缺口与整改建议 |
|---|---|---|---|---|---|
| M01 | 营业执照副本 | 有效、经营范围覆盖、盖章 | 营业执照扫描件 | 符合要求 | — |
| M02 | 近三年审计报告 | 3 个年度、审计意见、盖章 | 2023/2024 审计报告 | 部分符合 | 缺 2025 年；补审计报告并核对净资产 |
| M03 | 知识产权证明 | 权利人一致、有效 | 未提供 | 未提供 | 补专利证书/软著证书及缴费凭证 |

## 统计
- 符合要求：X
- 部分符合：X
- 不符合：X
- 无法判断：X
- 未提供：X

## 最影响申报的 3 个缺口
1. …
2. …
3. …

## 建议整改顺序
1. 先补硬性条件（主体/资质/财务/知识产权）
2. 再补盖章、签字、日期、份数
3. 最后补加分项和说明材料

> 以上只核对材料是否符合申报要求，不代表申报是否通过；最终以主管部门审核为准。
```

## 4. 续案摘要

```markdown
上次进度：
- 申报事项：
- 清单版本：
- 已核对：X / N
- 符合 X、部分符合 X、不符合 X、无法判断 X、未提供 X
- 最近更新：

继续核对未完成项，还是申报要求有更新？
```

## 5. 客户问“能不能过”时

```markdown
我只能判断材料是否符合申报要求，不能判断最终是否通过。
目前能确定的是：X 项符合、X 项有缺口（列出硬性缺口）。
最终结果以主管部门审核为准。
```
